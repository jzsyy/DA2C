# 实验概览

[English](experiments.md) | [简体中文](experiments.zh-CN.md) | [项目首页](../README.zh-CN.md)

## 评估范围

实验涵盖 BBH、GSM8K 和 MMLU 的13个任务、3,975道题，在 A100 上使用 Qwen3-8B 和 Qwen3.8-27B。报告数值为种子42、43、44三次运行的平均值。

对比方法包括 CoT、Self-Consistency、Best-of-N、BloomWise、MAD-M²、AgentPrune 和 MAPS (text-adapted)，另以 GPT-5.4 Direct、Reasoning 作为闭源能力参照。BLES 根据相邻层答案一致性在线早停，BLM 汇聚六层答案；MAPS 保留人格协作与反馈机制，适配文本任务。

## 分析内容

- **组件作用：** 诊断问题链、核查反馈、接纳审核和重新诊断。
- **路由策略：** 收益与成本感知路由，对比随机、固定、规则及仅考虑收益的选择。
- **预算权衡：** 4,000、8,000和16,000 token 调度目标下的准确率与在线用量。
- **第二基座：** 各基座分别校准路由器。

消融共享冻结的初始候选，各变体均计入完整生成成本，并在相同开发划分重新拟合路由器，沿用完整方法的选定超参数。

## 评价口径

主对比报告任务宏平均准确率，消融、路由与预算分析按全部题目计算微平均。在线用量包含生成、协作、选择及重试的输入与输出 token。主比较报告各方法的实际运行点，预算扫描用于 DA²C。
