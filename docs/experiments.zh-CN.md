# DA²C 实验设置说明

[English](experiments.md) | [简体中文](experiments.zh-CN.md) | [项目说明](../README.zh-CN.md)

本文档介绍论文采用的实验协议。实现代码、可执行配置及复现实验脚本计划在论文录用后发布。

## 评估协议

- 基座：Qwen3-8B、Qwen3.8-27B，模型权重冻结，两种基座分别校准路由器。
- 测试：13个任务、3,975题，包括六个BBH任务（每项250题）、GSM8K（1,319题）和六个MMLU任务（分别144、173、145、237、223、234题）。
- 种子：42、43、44。表格报告三次运行均值；纠错数和误改数先取均值，再取整。
- 主表总体准确率为13任务等权宏平均。消融、路由和预算准确率先在每次运行内合并全部题目计算微平均，再跨运行平均。
- 在线token包含初始生成、核查、干预、选择、审核和重试的输入与输出；离线路由校准和图优化与在线用量分开记录。

## 路由校准

开发协议从GSM8K训练集、MMLU验证集各抽取200题，以题目指纹排除测试重叠，按题划分60%拟合、20%选择、20%独立检查。动作分支复用相同的候选与诊断状态，每个动作重复两次；每个动作分别建模收益和对数成本。后续状态由固定种子的随机可用动作产生，不根据标准答案选择后续路径。

34维特征描述答案关系、格式与置信度有效性、诊断类别、认知操作、核查来源与结论、轮次及剩余预算。各动作使用拟合分区进行标准化，类别置信度保留为类别。代码发布时将一并提供精确编码器和路由文件中的特征顺序。

## 对比基线

| 方法 | 设置 |
| --- | --- |
| CoT | 单次生成 |
| Self-Consistency | 三候选及答案投票 |
| Best-of-N | 三候选；同基座选择器，其调用计入在线成本 |
| BloomWise-BLES | 相邻层有效答案一致时实际在线早停，否则采用末层答案 |
| BloomWise-BLM | 汇聚全部六层答案 |
| MAD-M² | 主观屏蔽，三个智能体，含初始化共两轮 |
| AgentPrune | 作者公开代码的图优化、剪枝及正则化；通用图在开发数据优化后迁移至BBH，数学图使用GSM8K训练数据 |
| MAPS (text-adapted) | 保留人格协作与反馈，移除视觉输入 |
| GPT-5.4 Direct / Reasoning | 单独列示的闭源能力参照 |

CoT、Self-Consistency、Best-of-N使用温度0.2、top-p = 1、每次最多2,048输出token，不调用计算器。AgentPrune数学角色保留代码执行。MAD-M²、BloomWise、AgentPrune不统一施加DA²C的8,000 token总调度目标。主对比报告各方法的实际运行点及在线用量。

## 受控消融

同题同种子的初始候选生成后冻结，各变体共享候选，但均计入完整生成成本。各变体在相同开发划分重新采集并拟合路由系数，沿用完整方法的alpha/lambda。

| 变体 | 改动 |
| --- | --- |
| Generic question chain | 保留具体陈述定位，移除认知类别和功能说明 |
| Fixed cognitive order | 按Remember至Create的预设顺序选择操作，最多三问，正常早停 |
| Shuffled question chain | 按种子打乱操作顺序，每次仍根据当前状态生成问题 |
| w/o Bloom labels | 类别名改为中性编号，保留功能说明和自适应选择 |
| w/o claim-level diagnosis | 按固定顺序选择首个匹配当前答案的候选并检查其完整解答；移除前置核查和verify_step，保留补证据、完整解答修订、仲裁和审核 |
| w/o diagnostic checking | 核查特征标记缺失，保留算术筛查及接纳审核 |
| w/o acceptance gate | 直接提交格式有效且未被算术筛查阻止的提案 |
| w/o re-diagnosis | 沿用初始诊断/核查记录，目标消失或重复动作时停止 |

诊断/核查缺失特征在校准和测试中采用一致的显式缺失编码。移除诊断核查仍保留诊断与定位；移除接纳审核仍保留诊断核查与算术筛查。
